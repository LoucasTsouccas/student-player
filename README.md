# Student Player

Αυτόνομη στατική εφαρμογή για παιδιά Δημοτικού, χωρίς λογαριασμούς, διαφημίσεις, καταγραφή μαθητών ή συνδέσμους προς εμπορική ιστοσελίδα.

## Τοπική εκτέλεση

Χρειάζεται Node.js 20 ή νεότερο. Δεν χρειάζεται εγκατάσταση πακέτων.

```sh
npm start
```

Ανοίξτε http://127.0.0.1:4173/ . Μην ανοίγετε το HTML με διπλό κλικ: η φόρτωση JSON χρειάζεται HTTP.

## Μόνιμες διευθύνσεις

Οι διαδρομές είναι σχετικές με τη βάση φιλοξενίας. Μπορούν να χρησιμοποιηθούν ως σελιδοδείκτες ή QR. Δεν αλλάζουν όταν αλλάζει η ανάθεση.

| Τάξη | Διαδρομή |
|---|---|
| Α΄ | classes/a/ |
| Β΄ | classes/b/ |
| Γ΄ | classes/c/ |
| Δ΄ | classes/d/ |
| Ε΄ | classes/e/ |
| Στ΄ | classes/st/ |

Κάθε διεύθυνση έχει πραγματικό index.html, για απευθείας φόρτωση και ανανέωση χωρίς κανόνες ανακατεύθυνσης.

## Αλλαγή ενεργού μαθήματος

Επεξεργαστείτε το assignments.json στη ρίζα. Τα κλειδιά a, b, c, d, e, st αντιστοιχούν στις έξι τάξεις. Η τιμή null εμφανίζει «Δεν υπάρχει ενεργό μάθημα για σήμερα». Διαφορετικά η τιμή είναι το όνομα αρχείου στο lessons/ χωρίς την κατάληξη .json.

Παράδειγμα: `"st": "therapeia-sygkyptousas"`. Για απενεργοποίηση: `"st": null`.

Προσθέστε νέο JSON ακολουθώντας το υπάρχον παράδειγμα: version, title, duration, source και pages. Κάθε οθόνη έχει title, text, minutes, προαιρετικές paragraphs και tasks. Οι δραστηριότητες υποστηρίζουν choice (choices, answer με αρίθμηση από 0, explanation, hint), match (options και rows με label, answer, hint), sequence (items, initialOrder, explanation) και reflect (minLength, model, criteria). Κάθε δραστηριότητα χρειάζεται μοναδικό id. Όταν αλλάζει ουσιαστικά το περιεχόμενο, αυξήστε το version ώστε να μη χρησιμοποιείται παλιά πρόοδος. Οι ελεύθερες απαντήσεις δεν βαθμολογούνται σημασιολογικά: ο μαθητής συγκρίνει με παράδειγμα και κάνει αυτοέλεγχο. Το περιεχόμενο εμφανίζεται ως απλό κείμενο, χωρίς εκτέλεση HTML.

Το ενεργό μάθημα αποτελείται από 12 οθόνες με ενδεικτικό συνολικό χρόνο 38 λεπτών (35–40 λεπτά ανάλογα με τον ρυθμό του παιδιού). Περιλαμβάνει αφήγηση, σειροθέτηση, ερωτήσεις βιβλίου, καθοδηγούμενη γραφή, ΠΡΙΝ–ΜΕΤΑ, σύγκριση παραδόσεων, αρχαίες λέξεις, σημερινό παράδειγμα και exit ticket. Οι απαντήσεις αποθηκεύονται στο sessionStorage της ίδιας καρτέλας, για επαναφορά μετά από ανανέωση, και δεν αποστέλλονται σε διακομιστή. Το κλείσιμο της καρτέλας συνήθως τις διαγράφει· η επαναφορά καρτελών από τον browser μπορεί να τις διατηρήσει. Η «Νέα προσπάθεια» στο τέλος τις καθαρίζει μετά από επιβεβαίωση.

## Δημοσίευση

Ανεβάστε τα στατικά αρχεία σε οποιονδήποτε στατικό host, είτε σε domain είτε σε υποφάκελο. Για GitHub Pages επιλέξτε Settings → Pages → Deploy from a branch → main → / (root). Με τη συνήθη διεύθυνση Pages η είσοδος της Στ΄ θα είναι https://loucastsouccas.github.io/student-player/classes/st/ . Η διεύθυνση αυτή λειτουργεί μόνο αφού ενεργοποιηθεί και ολοκληρωθεί η δημοσίευση. Το commit/push από μόνο του δεν ενεργοποιεί hosting.

## Έλεγχοι

`npm test` ελέγχει τις σταθερές εισόδους, τις αναθέσεις, τα μαθήματα και την εξυπηρέτηση HTTP, συμπεριλαμβανομένου αποκλεισμού αρχείων εκτός εφαρμογής.

## Πηγές και σχεδιασμός μαθήματος

- Επίσημο βιβλίο ΥΠΑΝ, «Πορεία μέσα στην αγάπη», Μέρος Α΄, έντυπες σ. 24–26: https://sch.cy/sd/237/thriskeftika_st_dim_meros_a.pdf . Οι τρεις ερωτήσεις της οθόνης 5 αντιστοιχούν στην άσκηση 1 της σ. 25. Οι υπόλοιπες ασκήσεις έχουν νέα διατύπωση.
- Αφήγηση: ελεύθερη διδακτική απόδοση Λουκά 13:10–17. Η αναφορά στο Σάββατο που έγινε για τον άνθρωπο αποδίδεται χωριστά στον Μάρκο 2:27.
- Για το Σαμπάτ και την προτεραιότητα διάσωσης ζωής: https://www.chabad.org/library/article_cdo/aid/633659/jewish/What-Is-Shabbat.htm και https://www.chabad.org/library/article_cdo/aid/1113745/jewish/Saving-Lives-on-Shabbat.htm . Οι πρακτικές διαφέρουν μεταξύ κοινοτήτων· η ιστορία δεν γενικεύει τη στάση του αρχισυνάγωγου σε όλους τους Ιουδαίους.

Η διάρκεια είναι διδακτική εκτίμηση για προσεκτική ανάγνωση, γραφή και αναστοχασμό, όχι μετρημένο αποτέλεσμα δοκιμής με τάξη. Δεν επιβάλλεται αναμονή. Όλες οι δραστηριότητες ολοκληρώνονται με πληκτρολόγιο ή αφή, χωρίς υποχρεωτικό drag-and-drop. Οι αντικειμενικές ερωτήσεις επιτρέπουν απεριόριστες διορθώσεις. Το exit ticket αναφέρει χωριστά τις σωστές πρώτες προσπάθειες.
