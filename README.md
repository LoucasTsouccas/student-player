# Student Player

Αυτόνομο μαθητικό περιβάλλον Δημοτικού. Το περιεχόμενο φορτώνεται αποκλειστικά από δημόσιο CSV σε κάθε άνοιγμα τάξης. Δεν χρειάζεται νέο commit ή deployment για αλλαγή ανάθεσης, τίτλου, κειμένου ή οθονών μέσα στο ίδιο feed.

## Πηγή μαθημάτων

Το assets/feed.js ορίζει το FEED_URL που δόθηκε για την καρτέλα PublicFeed (gid=236172835):

https://docs.google.com/spreadsheets/d/1K5p8weVhnbY6ygdl2rmreslnfeNsHB_vw0X0E_FhuoY/export?format=csv&gid=236172835

Το Sheet πρέπει να είναι διαθέσιμο ως «Anyone with the link → Viewer», ώστε το endpoint /export?format=csv να επιστρέφει CSV χωρίς σύνδεση. Εναλλακτικά υποστηρίζεται δημόσιο CSV από «Δημοσίευση στον ιστό». Ένα URL /edit δεν είναι δημόσιο CSV. Αν επιστρέφεται 401/404 ή σελίδα HTML, το μάθημα δεν φορτώνει. Η εφαρμογή δεν χρησιμοποιεί το συνδεδεμένο Google account του διαχειριστή, credentials, ιδιωτικά APIs, iframe ή ανακατεύθυνση σε Google Sheets.

Το ενεργό endpoint χρησιμοποιεί εξαγωγή CSV από το κοινόχρηστο Public Feed Sheet, gid=236172835. Επιβεβαιώστε την ανώνυμη πρόσβαση με αποσυνδεδεμένο browser. Αν αλλάξει το αρχείο ή η καρτέλα, απαιτείται μία αλλαγή του FEED_URL· οι καθημερινές αλλαγές περιεχομένου και αναθέσεων στο ίδιο Sheet δεν απαιτούν deployment. Η υπηρεσία Google μπορεί να χρειαστεί λίγο χρόνο για να ανανεώσει τις αποκρίσεις της.

### Ανανέωση και σφάλματα

Κάθε φόρτωση τάξης, ανανέωση, επαναφορά από το back/forward cache ή πάτημα «Δοκίμασε ξανά» κάνει νέα ανώνυμη ανάκτηση με cache: no-store και μοναδική παράμετρο _sp. Δεν υπάρχει cache CSV στον Player, service worker ή local fallback. Μετά από 20 δευτερόλεπτα η εκκρεμής αίτηση ακυρώνεται.

Αν αποτύχει η ανάκτηση ή η επικύρωση, εμφανίζεται: «Το μάθημα δεν μπόρεσε να φορτωθεί. Δοκίμασε ξανά σε λίγο.» με κουμπί επανάληψης. Δεν προβάλλεται παλιό τοπικό μάθημα. Τα παλιότερα assignments.json και lessons/*.json διατηρούνται μόνο ως ιστορικά αρχεία και δεν διαβάζονται από τον Player. Το tests/fixtures/public-feed.csv είναι αποκλειστικά στιγμιότυπο για tests· δεν εξυπηρετείται από τον τοπικό server και δεν χρησιμοποιείται στην εφαρμογή.

## Δομή PublicFeed

Απαιτούμενες επικεφαλίδες (η σειρά μπορεί να αλλάξει):

`record_type,class_key,lesson_id,step_no,type,title,prompt,content,choices_json,correct_answer,feedback`

- assignment: μία γραμμή ανά class_key (a, b, c, d, e, st). Το lesson_id ορίζει το ενεργό μάθημα. Κενό lesson_id ή απουσία γραμμής εμφανίζει «Δεν υπάρχει ενεργό μάθημα για σήμερα». Διπλή ανάθεση απορρίπτεται ως αμφίσημη.
- lesson: μία γραμμή με μοναδικό lesson_id, title και προαιρετικό content ως βασική ιδέα.
- screen: μία γραμμή ανά οθόνη του lesson_id. Το step_no είναι θετικός μοναδικός ακέραιος. Η ταξινόμηση γίνεται αριθμητικά, όχι από τη θέση της γραμμής.

Το choices_json είναι πάντα JSON array (κενό κελί ισοδυναμεί με []). Τα κείμενα εμφανίζονται ως απλό κείμενο, ποτέ ως HTML ή JavaScript. Τα teacher_note, διαχειριστικά πεδία και διευθύνσεις διαχείρισης δεν προβάλλονται από τον Player. Δεν προσθέτουμε στο δημόσιο feed προσωπικά δεδομένα ή μυστικά.

### Τύποι οθονών

| type | Συμπεριφορά |
|---|---|
| intro | Εισαγωγή και επιλογή με έλεγχο όταν υπάρχει correct_answer, αλλιώς προσωπική επιλογή ή γραπτή σκέψη. |
| info | Κείμενο και λίστα βασικών λέξεων από choices_json· ελεύθερη συνέχεια όταν δεν υπάρχει ερώτηση με σωστή απάντηση. |
| story | Αφήγηση και προαιρετική ερώτηση επιλογής. |
| sequence | Γεγονότα με κουμπιά ↑/↓, χωρίς ανάγκη drag-and-drop. |
| mcq | Επιλογές με άμεσο feedback και απεριόριστες διορθώσεις. |
| interpretation | Ερώτηση επιλογής ή γραπτή ερμηνεία με καθοδήγηση. |
| before_after | Αντιστοίχιση περιγραφών σε ΠΡΙΝ/ΜΕΤΑ ή γραπτός αναστοχασμός. |
| compare | Αντιστοίχιση στοιχείων σε κατηγορίες ή προσωπική σύγκριση. |
| matching | Αντιστοίχιση ζευγών από choices_json. |
| application | Επιλογή σε σημερινό παράδειγμα ή γραπτή εφαρμογή. |
| exit | Ερώτηση επιλογής ή ξεχωριστά πεδία για αριθμημένες ανοικτές ερωτήσεις. |

### Απαντήσεις και δομημένα πεδία

- Επιλογές: choices_json π.χ. `["Απάντηση Α","Απάντηση Β"]`. Το correct_answer είναι θέση από το **0** (0 = πρώτη απάντηση) ή το ακριβές κείμενο της επιλογής. Κενό correct_answer δεν θεωρείται μηδέν και δεν δηλώνεται αυθαίρετα σωστή απάντηση.
- Σειροθέτηση: choices_json ως array γεγονότων ή content με `1. Γεγονός … 2. Γεγονός …`. Το correct_answer είναι λίστα αριθμών γεγονότων από το **1**, π.χ. `3,1,2` ή `[3,1,2]`. Αν είναι κενό, η σειρά εισαγωγής ορίζει τη λύση. Η αρχική παρουσίαση είναι ανακατεμένη.
- Matching: choices_json π.χ. `["γυνή=γυναίκα","ὄχλος=πλήθος"]` ή `[{"left":"γυνή","right":"γυναίκα"},{"left":"ὄχλος","right":"πλήθος"}]`. Τα ζεύγη καθορίζουν τη σωστή αντιστοίχιση. Προαιρετικό correct_answer: JSON array μηδενικών δεικτών προς τις μοναδικές δεξιές επιλογές όπως εμφανίζονται (αντίστροφη σειρά πρώτης εμφάνισης). Συνιστάται να παραμένει κενό όταν η λύση δίνεται ήδη από τα ζεύγη.
- Σύγκριση: choices_json π.χ. `["Κοινό: ανάπαυση","Κυριακή: Ανάσταση","Σάββατο: Σαμπάτ"]`. Το κείμενο πριν από το : είναι η κατηγορία.
- Πριν/Μετά: content στη μορφή `ΠΡΙΝ: περιγραφή, περιγραφή. ΜΕΤΑ: περιγραφή, περιγραφή.`. Οι περιγραφές χωρίζονται σε κόμματα ή «και» και γίνονται αντιστοίχιση. Για πιο σύνθετη δραστηριότητα μπορεί να χρησιμοποιηθεί matching.
- Exit χωρίς choices: content με αριθμημένες ερωτήσεις `1. Ερώτηση; 2. Ερώτηση; …` δημιουργεί αντίστοιχα ξεχωριστά πεδία γραφής.
- Ανοικτές απαντήσεις: το feedback λειτουργεί ως καθοδήγηση αυτοελέγχου. Δεν γίνεται αυτόματη σημασιολογική βαθμολόγηση.

Το feedback εμφανίζεται μετά τον έλεγχο ή την επιλογή όπου εφαρμόζεται. Προαιρετικές στήλες minutes στις οθόνες και duration στο lesson μπορούν να προστεθούν για πληροφορία χρόνου.

## Πρόοδος και μαθητικό περιβάλλον

Μεγάλα γράμματα, ευδιάκριτη πρόοδος, κουμπιά Πίσω/Συνέχεια και χειρισμός με αφή ή πληκτρολόγιο. Οι απαντήσεις διατηρούνται στο sessionStorage της ίδιας καρτέλας, χωρίς αποστολή τους σε διακομιστή. Με αλλαγή περιεχομένου αλλάζει το fingerprint του μαθήματος και καθαρίζεται η παλιά πρόοδος. Η αποθήκευση απαντήσεων δεν υποκαθιστά την εκ νέου ανάκτηση του feed.

## Τοπική εκτέλεση και tests

Χρειάζεται Node.js 20+. Δεν χρειάζεται εγκατάσταση πακέτων για την εφαρμογή ή τα unit tests.

```sh
npm start
npm test
```

Τοπικό URL: http://127.0.0.1:4173/ . Και τοπικά η εφαρμογή διαβάζει το πραγματικό απομακρυσμένο feed· δεν υποστηρίζει διπλό κλικ σε HTML ή offline λειτουργία.

Τα unit tests καλύπτουν RFC-style CSV, quoted κόμματα και αλλαγές γραμμής, επιλογή ενεργού μαθήματος, ταξινόμηση, 11 τύπους οθονών, σωστές απαντήσεις, απουσία ανάθεσης, malformed δεδομένα, αλλαγή περιεχομένου, cache-busting, timeout και σφάλματα δικτύου. Το στιγμιότυπο PublicFeed λήφθηκε στις 22/10/2026 και περιέχει το therapeia-sygkyptousas με 12 οθόνες. Δεν αποτελεί απόδειξη ότι το δημόσιο URL είναι διαθέσιμο.

Προαιρετικό browser test: με Playwright εγκατεστημένο εκτελέστε `npm run test:browser`. Μπορείτε να ορίσετε PLAYWRIGHT_MODULE σε εγκατεστημένο module και BROWSER_EXECUTABLE σε διαθέσιμο Chrome/Chromium. Χωρίς BROWSER_EXECUTABLE χρειάζεται `npx playwright install chromium`. Οι δοκιμές χρησιμοποιούν ελεγχόμενες HTTP απαντήσεις από το fixture μόνο στο test context και ελέγχουν desktop, μεγάλη οθόνη αφής και στενή οθόνη. Διατρέχουν όλες τις οθόνες και τις έξι τάξεις, αποτυχία, retry, ανανέωση, αλλαγή δεδομένων, πλοήγηση Πίσω και απουσία τοπικού fallback. Δεν προσομοιώνουν την προσβασιμότητα ή τον χρόνο δημοσίευσης της Google· ο ζωντανός ανώνυμος έλεγχος πρέπει να γίνει χωριστά.

## Ξεχωριστά προφίλ εκπαιδευτικών

Η Ευγενία χρησιμοποιεί το evgenia/classes/d/ με data-grade="d", data-class-key="evgenia-d", data-profile="evgenia" και εμφανιζόμενη τάξη Δ΄1. Ο ίδιος Player φορτώνει την αντίστοιχη ανάθεση από το κοινό feed. Το data-grade διατηρεί την εμφάνιση/επικύρωση της βασικής τάξης, ενώ το data-class-key επιλέγει την ανάθεση. Αν απουσιάζει, χρησιμοποιείται το data-grade. Το προφίλ προεπιλογής είναι default. Τα κλειδιά προόδου περιλαμβάνουν προφίλ, class key και lesson id. Προφίλ και class keys επιτρέπουν πεζά λατινικά, αριθμούς και ενδιάμεσες παύλες, έως 64 χαρακτήρες. Η πρώτη χρήση του νέου namespace ξεκινά καθαρή πρόοδο· δεν εισάγονται παλιές απαντήσεις χωρίς προφίλ.
