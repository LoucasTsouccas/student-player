# Student Player

Αυτόνομη στατική εφαρμογή για παιδιά Δημοτικού, χωρίς λογαριασμούς, διαφημίσεις, καταγραφή μαθητών ή συνδέσμους προς εμπορική ιστοσελίδα.

## Τοπική εκτέλεση

Χρειάζεται Node.js 20 ή νεότερο. Δεν χρειάζεται εγκατάσταση πακέτων.

```sh
npm start
```

Ανοίξτε http://127.0.0.1:4173/ . Μην ανοίγετε το HTML με διπλό κλικ: η φόρτωση JSON χρειάζεται HTTP.

## Μόνιμες διευθύνσεις

Οι διαδρομές είναι σχετικές με τη βάση φιλοξενίας. Μπορούν να χρησιμοποιηθούν ως σελιδοδείκτες ή QR. Δεν αλλάζουν όταν αλλάζει η ανάθεση.

| Τάξη | Διαδρομή |
|---|---|
| Α΄ | classes/a/ |
| Β΄ | classes/b/ |
| Γ΄ | classes/c/ |
| Δ΄ | classes/d/ |
| Ε΄ | classes/e/ |
| Στ΄ | classes/st/ |

Κάθε διεύθυνση έχει πραγματικό index.html, για απευθείας φόρτωση και ανανέωση χωρίς κανόνες ανακατεύθυνσης.

## Αλλαγή ενεργού μαθήματος

Επεξεργαστείτε το assignments.json στη ρίζα. Τα κλειδιά a, b, c, d, e, st αντιστοιχούν στις έξι τάξεις. Η τιμή null εμφανίζει «Δεν υπάρχει ενεργό μάθημα για σήμερα». Διαφορετικά η τιμή είναι το όνομα αρχείου στο lessons/ χωρίς την κατάληξη .json.

Παράδειγμα: `"st": "therapeia-sygkyptousas"`. Για απενεργοποίηση: `"st": null`.

Προσθέστε νέο JSON ακολουθώντας το υπάρχον παράδειγμα: title, source και pages. Κάθε σελίδα έχει title και text. Προαιρετικά έχει choices (πίνακα επιλογών), answer (θέση σωστής απάντησης, αρχίζοντας από 0) και explanation. Επιτρέπονται πεζά λατινικά γράμματα, αριθμοί και παύλες στο όνομα αρχείου. Το περιεχόμενο εμφανίζεται ως απλό κείμενο, χωρίς εκτέλεση HTML.

Το πρώτο μάθημα είναι μια σύντομη διδακτική απόδοση του Λκ 13, 10–17, με δύο ερωτήσεις και μια δραστηριότητα συζήτησης. Οι απαντήσεις παραμένουν μόνο στη μνήμη της ανοιχτής σελίδας.

## Δημοσίευση

Ανεβάστε τα στατικά αρχεία σε οποιονδήποτε στατικό host, είτε σε domain είτε σε υποφάκελο. Για GitHub Pages επιλέξτε Settings → Pages → Deploy from a branch → main → / (root). Με τη συνήθη διεύθυνση Pages η είσοδος της Στ΄ θα είναι https://loucastsouccas.github.io/student-player/classes/st/ . Η διεύθυνση αυτή λειτουργεί μόνο αφού ενεργοποιηθεί και ολοκληρωθεί η δημοσίευση. Το commit/push από μόνο του δεν ενεργοποιεί hosting.

## Έλεγχοι

`npm test` ελέγχει τις σταθερές εισόδους, τις αναθέσεις, τα μαθήματα και την εξυπηρέτηση HTTP, συμπεριλαμβανομένου αποκλεισμού αρχείων εκτός εφαρμογής.
